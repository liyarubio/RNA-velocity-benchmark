# Archived TopoVelo predictions

The derived directory contains saved GDC cluster/edge summaries, directions and paired-context results. The original ST_small/ST_raw H5ADs and superseded layout input are external; their SHA256 and sizes are recorded in the release source ledger. Training settings were unavailable. Run the repository-level latest-results check for aggregate recalculation. The projection implementation is in 09_Core/shared/latest and requires external H5ADs plus scVelo 0.2.5.
