# Shared Figure 3 helpers

[figure3_common.R](figure3_common.R) contains shared readers, method labels, colors and export helpers. Each panel has its own plotting script.

The former combined simulation notebook has been split into independent [a](../a/generate_metrics.ipynb), [b](../b/generate_metrics.ipynb), [c](../c/generate_metrics.ipynb), [d](../d/generate_metrics.ipynb) and [f](../f/generate_metrics.ipynb) notebooks. Each includes its required original preparation cells and only its relevant metric blocks. Panel f also includes its global, in-cluster and directional metrics. The historical code requires external inputs and was not executed.

[Auxiliary PCA30 metrics](pca30_auxiliary_metrics.ipynb) preserve the original standalone PCA30 calculation; it is not a separate manuscript panel.
